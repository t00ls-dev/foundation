# Segurança

## Divulgação responsável

Não publique vulnerabilidades exploráveis, tokens, dados pessoais ou detalhes de
acesso em issues, PRs ou logs públicos.

Use **Security → Advisories → Report a vulnerability** no repositório
`t00ls-dev/foundation` para enviar um relato privado. O canal estava habilitado
na verificação de 31/10/2026.

No relato privado, informe versão/SHA afetado, impacto, passos de reprodução
locais e eventual correção, usando dados sintéticos. Não teste contra DEV ou
serviços de terceiros sem autorização.

## Correções

O projeto está em fase inicial. A revisão de segurança concentra-se na base
atual; ainda não há matriz de versões mantidas, SLA de resposta ou promessa de
backports. Essas decisões devem ser definidas pelo mantenedor conforme a adoção.

Veja o [runbook de segurança](docs/runbooks/security.md) e o
[processo de contribuição](CONTRIBUTING.md). Divulgação pública de detalhes deve
ser coordenada após a avaliação e disponibilização da correção.
